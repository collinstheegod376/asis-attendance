WORK ITEMS — implement in this order

STEP 1 — Reverse proxy for production (fixes PERF-04, PERF-05, G4)
  File: infra/nginx.conf or infra/Caddyfile
  - Serve the Student PWA static files from `/`.
  - Serve the Admin Portal static files from `/admin/` on a SEPARATE host
    (e.g. admin.yourdomain.com) OR from `/admin/*` on the same host. Prefer
    separate host to keep cookie scope clean.
  - Reverse proxy `/api/*` to `https://<project-ref>.supabase.co/functions/v1/*`
    with:
      proxy_set_header Host $host;
      proxy_set_header X-Real-IP $remote_addr;
      proxy_pass_request_headers on;
      # Preserve and forward Set-Cookie from the origin
      proxy_cookie_path / /;
  - CRITICAL: do not strip the Authorization, Cookie, or Set-Cookie headers.
  - TLS certificate from Let's Encrypt. HSTS enabled.

STEP 2 — Local development parity
  File: docker-compose.yml (or documented local nginx)

    cookie behaviour on real phones before deployment.
  - Document the mkcert CA installation for iOS/Android.

STEP 3 — Environment and secret hygiene (fixes PERF-19)
