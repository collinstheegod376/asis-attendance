CONSTRAINTS — non-negotiable
1. The student PWA never talks to Supabase tables or RPCs directly in
   production. All student actions go through Edge Functions under `/api/*`.
   Vite dev proxy provides the same-origin illusion in development.
2. Never trust the client to authorize itself. The client soft-lock exists as
   UX convenience only; the server is always authoritative.
3. Every redirect to a terminal state (`/expired`, `/closed`, `/already-signed`,
   `/not-enrolled`, `/block/*`) MUST use `navigate(path, { replace: true })` and
   MUST clear attempt state from sessionStorage.
4. Every block screen must display the exact reference code returned by the
   server (including hex suffix), not a hardcoded prefix.
5. Camera `MediaStream` tracks must be stopped immediately after capture, and
   again on component unmount, and again on visibilitychange to hidden.
6. Location verification must be fail-closed. Any error, timeout, or
   non-success response blocks progression to `/attend/selfie`.
7. Idempotency key is generated ONCE when the attempt is created (server-side)
   and reused for every retry of the submit call.
8. The selfie is uploaded via an Edge Function (`/api/upload-selfie`) that
   returns the canonical storage path. Client never constructs the path itself.
9. The video step is instructional only. The submit button is NEVER disabled
   because of video state. The spec is explicit.
10. Every `/attend/*` page must guard against out-of-order navigation by
    checking attempt state from sessionStorage. A direct URL to a later step
    when an earlier step is incomplete must redirect to the correct step.
