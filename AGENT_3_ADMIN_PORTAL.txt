CONSTRAINTS — non-negotiable
1. Replace localStorage mock auth with real Supabase Auth
   (supabase.auth.signInWithPassword). The session is stored in
   Supabase's own auth storage; no `adun_portal_session_user` key.
2. Remove the 3-second `syncFromSupabase` polling loop entirely. Use
   Supabase Realtime subscriptions for live data where needed.
3. Every mutation must write to Supabase tables or Edge Functions FIRST,
   then refresh local state from the successful server response. Never write
   to localStorage as source of truth.
4. Every lecturer-scoped route must verify `course.lecturer_id === user.id`
   before rendering (in addition to RLS). Redirect unauthorised users to
   /lecturer/dashboard with a toast.
5. Every date rendered or bucketed uses Africa/Lagos (WAT, UTC+1) via
   Intl.DateTimeFormat. Never use the browser's local timezone for logic.
6. Every reference code displayed uses the unified BIND-200..BIND-206
   taxonomy from _shared/reference-codes.ts, with prefix matching for
   filtering (startsWith), never equality against the bare prefix.
7. Every Excel export must reflect exactly what the UI shows, joined with
   students_master for matric and name, and includes signed selfie references.
8. `must_change_password` is persisted in Supabase and cleared after a
   successful change. No infinite password-change loop.
9. Admin can never edit or delete attendance_records from the UI or API.
10. Roster import rejects unknown matric numbers. It never auto-creates
    students in students_master.

WORK ITEMS — implement in this order

STEP 1 — Real Supabase Auth (fixes SEC-16, QA-03)
  Files: admin-portal/src/context/AuthContext.tsx,
         admin-portal/src/pages/LoginPage.tsx,
         admin-portal/src/services/authService.ts
  - Remove all localStorage-based session logic.
  - On login: supabase.auth.signInWithPassword({ email, password })
  - Fetch the user's role from public.users after login:
      select * from users where auth_id = session.user.id and status = 'active'
  - If must_change_password is true, force the modal and block all routes
    except /change-password.
  - On password change:
      await supabase.auth.updateUser({ password: newPassword })
      await supabase.from('users').update({ must_change_password: false })
        .eq('id', user.id)
  - LoginPage redirect:
      if role === 'admin' -> navigate('/admin/home')
      else -> navigate('/lecturer/dashboard')
  - Auth context exposes { user, role, loading, signOut }.
  - Route guards: <AdminRoute> and <LecturerRoute> check role from context,
    not from localStorage.

STEP 2 — Remove the destructive 3s full-table poll (fixes QA-02, PERF-03)
  File: admin-portal/src/lib/storage.ts
  - Delete `startServerSync`, `syncFromSupabase`, and any setInterval.
  - Delete `setRawItem`, `getRawItem`, and localStorage-based persistence
    for courses, sessions, roster, users, device_bindings, attendance.
  - Replace with typed service functions that read from Supabase directly
    per page/component. Add a lightweight Realtime subscription only where
    the UI must update without a manual refresh (e.g. live session attendance
    count). Do not subscribe to attendance_records globally.
  - localStorage may be used ONLY for UI preferences (sidebar state, theme,
    last-selected course), never for business data.

STEP 3 — Wire all lecturer mutations to Supabase (fixes QA-02, QA-17, QA-18)
  File: admin-portal/src/services/lecturerService.ts
  - createCourse -> supabase.from('courses').insert(...)
  - archiveCourse -> supabase.from('courses').update({ status: 'archived' })
      AND close all active lecture_sessions for that course
      AND trigger any dependent RPCs
  - createLectureSession -> supabase.from('lecture_sessions').insert(...)
      Compute status from starts_at: 'scheduled' if future, else 'active'.
      Enforce duration <= settings.max_session_duration_minutes by REJECTING,
      not clamping.
  - closeLectureSession -> update status = 'closed'
  - revokeLectureSession -> update status = 'revoked'  (NEW action, add UI)
  - importCourseRoster -> call a new Edge Function /api/import-roster that
      validates every row against students_master in bulk. Reject unknown.
      Return { accepted: [...], rejected: [...] } with reasons.
  - resetDeviceBinding -> /api/reset-device-binding with JWT, never body.actor_id
  - deleteUser (soft) -> update users.status = 'soft_deleted'
      AND archive their courses (or reassign, per UI prompt)
      AND close active sessions of archived courses
      AND preserve all attendance_records
  - deleteCourse (soft) -> archive course, close sessions, DO NOT delete
      attendance_records
  - Every service function returns { success, data, error } and never throws
    on a controlled server error.

STEP 4 — Course ownership checks on every lecturer route (fixes SEC-17)
